# Proyecto de Design Thinking para Programación Móvil

## Descripción del proyecto

Durante el semestre, cada equipo diseñará y desarrollará una aplicación móvil siguiendo la metodología de Design Thinking.

El reto consiste en desarrollar un sistema de innovación para la Universidad del Norte.

La plataforma deberá permitir que los estudiantes puedan:

- Proponer ideas innovadoras.
- Explorar ideas propuestas por otros estudiantes.
- Unirse a las ideas que les interesen.
- Crear equipos de trabajo alrededor de una idea.
- Desarrollar y prototipar soluciones de manera colaborativa.
- Publicar los prototipos para la comunidad universitaria.
- Recibir apoyos, comentarios y validación mediante encuestas.

El objetivo no es solamente construir una aplicación móvil, sino asegurarse de que la aplicación responda a necesidades reales de sus usuarios.

## Metodología

El proyecto seguirá las fases de Design Thinking:

1. Empatizar.
2. Definir.
3. Idear.
4. Prototipar.
5. Probar.

Cada semana, los equipos realizarán una actividad específica y entregarán los resultados correspondientes.

Durante las primeras semanas, el trabajo estará enfocado en comprender a los usuarios y validar el problema antes de comenzar la implementación de la solución.

## Ruta de trabajo hasta la semana 5

- `semana-01`: comprender a los usuarios y al ecosistema de innovación.
- `semana-02`: definir con claridad el problema y las necesidades prioritarias.
- `semana-03`: generar ideas y seleccionar una propuesta de valor inicial.
- `semana-04`: integrar los flujos aprobados en un prototipo más completo y validarlo con mayor alcance.
- `semana-05`: probar el prototipo con usuarios y recoger aprendizajes para iterar.
